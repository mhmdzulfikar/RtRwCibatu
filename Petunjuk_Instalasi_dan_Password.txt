---
Sebelum menjalankan aplikasi, pastikan komputer/laptop sudah ter-install:
1. Node.js (Disarankan versi 18 ke atas). Bisa di-download di: https://nodejs.org/
2. Code Editor (Contoh: Visual Studio Code) untuk membuka kodenya.


---
3. CARA MENJALANKAN PROGRAM (RUNNING)
---
Anda perlu membuka DUA (2) terminal/CMD yang berbeda. Satu untuk Backend, satu untuk Frontend.

LANGKAH A: Menyalakan Backend (Database & API)
1. Buka CMD/Terminal.
2. Masuk ke folder backend: 
   cd backend
3. Install dependencies:
   npm install
4. Siapkan database SQLite:
   npx prisma generate
   npx prisma db push
   npx prisma db seed
5. Jalankan server:
   npm run dev
(Backend akan menyala dan *standby* di http://localhost:3001)

LANGKAH B: Menyalakan Frontend (Tampilan Web)
1. Buka CMD/Terminal BARU (biarkan terminal backend tetap menyala).
2. Pastikan Anda berada di folder utama proyek (bukan di dalam folder backend).
3. Install dependencies:
   npm install
4. Jalankan tampilan web:
   npm run dev
(Aplikasi sekarang bisa dibuka di browser melalui link: http://localhost:3000)

Selesai! Anda sekarang bisa login menggunakan akun di atas.
